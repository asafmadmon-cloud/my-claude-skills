A growing collection of custom skills for [Claude Code](https://claude.ai/code) —
each one designed to solve a specific problem across different domains.
Feel free to use, fork, or adapt any skill for your own projects.

## 📦 Skills

| Skill | Description | Domain |

| [strategic-stock-analysis-pilot](./strategic-stock-analysis-pilot/README.md) | Warren Buffett-style stock & ETF analysis with Buffett Score (0–100) | Investment Research |

---

## ⚙️ How to Install a Skill

Copy the skill folder into your Claude Code project's `.claude/skills/` directory:

```
your-project/
└── .claude/
    └── skills/
        └── <skill-name>/
```
